# Módulos da Fase 2

Domínios locais: stores, plans, products, categories, orders, inventory e billing. commerce contém a unidade transacional compartilhada, o adapter in-memory exclusivo de testes e os testes que integram os módulos.

Entidades e casos de uso não dependem de React, DOM, browser ou provedores. Não há UI comercial ou serviços externos. Ver docs/01-ARQUITETURA.md e docs/07-TESTES.md.
